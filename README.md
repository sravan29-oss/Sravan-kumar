## 🚀 Running Locally

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

3. **Build for Production**:
   ```bash
   npm run build
   ```
   The production-ready assets are bundled into the `dist/` directory with code splitting.

4. **Preview Production Build**:
   ```bash
   npm run preview
   ```
